LAN Backup · your files stay on your network

Back up, restore, and sync over your local network.

Install the phone app separately from the companion server. The server runs on your own Windows, Linux, or macOS computer and receives files directly over your local network.

Install the computer server

Choose the operating system of the computer that will store your files.

Windows · Linux · macOS 
Choose an operating system to show the setup command.

On the computer, open PowerShell or Terminal, then paste the copied command.

The browser cannot run an installer on your computer. The setup command downloads the server package from GitHub, checks or installs Node.js, and starts the server. Review the script source before running it if you prefer.

Windows setup and Desktop shortcut
  1. Open PowerShell as your normal user—not as Administrator.
  2. Run the command above. It creates %USERPROFILE%\LAN_backup, downloads setup.ps1, and starts setup.
  3. Setup downloads and extracts the server into LAN_backup\companion-server. It checks for Node.js and installs it when needed.
  4. On first run, copy the generated authentication token into LAN Backup → Settings → Auth Token. The token is saved in companion-server\.env; keep it private.
  5. Setup creates Start LAN Backup Server on the Desktop with the LAN Backup icon. Double-click it to start the server later. Its terminal window stays open while running; press Ctrl+C to stop it.
Linux setup and Desktop shortcut
  1. Open Terminal and run the command above. It installs in ~/LAN_backup/companion-server.
  2. If Node.js is missing, setup uses the supported package manager and may request your password. The server starts in Terminal.
  3. On first run, copy the generated authentication token into LAN Backup → Settings → Auth Token. It is saved in companion-server/.env; keep it private.
  4. Setup creates Start LAN Backup Server on the Desktop with the LAN Backup icon. Some desktop environments ask you to right-click the shortcut and choose Allow Launching. Press Ctrl+C in Terminal to stop the server.
macOS setup and Desktop shortcut
  1. Open Terminal and run the command above. It installs in ~/LAN_backup/companion-server.
  2. If Node.js is missing, setup uses Homebrew when available; otherwise it downloads the official Node.js installer. The server starts in Terminal.
  3. On first run, copy the generated authentication token into LAN Backup → Settings → Auth Token. It is saved in companion-server/.env; keep it private.
  4. Setup creates Start LAN Backup Server.app on the Desktop with the LAN Backup icon. Open it to start the server in Terminal. Press Ctrl+C in Terminal to stop it.

Keep the phone and computer on the same trusted Wi-Fi or LAN. The server uses port 7823 by default. If your firewall asks, allow access on the private network only; setup does not change firewall rules. Do not expose the server to the public internet.

Manual server package downloads

Most users should run the setup command above. For manual installs:

  • Windows ZIP package
  • Linux/macOS TAR.GZ package
  • SHA-256 checksums
